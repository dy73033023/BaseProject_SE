# 생성 자산 기록

- 생성 방식: 내장 imagegen 도구. 외부 API/CLI는 사용하지 않음.
- 용도: 기존 OpenGL 프로젝트의 런타임 스프라이트.
- 저장 위치: 이 문서와 같은 Assets 폴더. 생성 원본은 별도 기본 저장 위치에 보존.
- 검토: 이미지 내용과 투명 알파 확인. 적 시트의 행 간격은 런타임 UV로 보정.
- 아래 영문은 재현을 위해 보존한 실제 최종 생성 프롬프트이며 게임 UI 문구가 아니다.

## titus-deathwatch-walk.png

```text
Use case: stylized-concept. Create a production game sprite sheet PNG with a TRUE TRANSPARENT background, not a checkerboard. Square 2048x2048 image, exact 4 columns by 4 rows equal 512x512 cells, no borders, no labels, no text. Each cell contains the SAME full-body Titus in Deathwatch black power armour from Warhammer 40,000 Space Marine 2 prologue, silver left arm and left pauldron, unmarked black right pauldron, red helmet eye lenses, heavy backpack, worn black ceramite with silver edge scratches, muted brass chest insignia, thick segmented boots, carrying a compact bolter across chest. AAA pre-rendered isometric RPG sprite, realistic finely detailed painted metal, NOT cartoon or pixel art. Orthographic camera 35 degrees looking down; consistent scale and upper-left lighting. Four facing rows: top row facing screen down-right; second row down-left; third row up-left showing back; fourth row up-right showing back. Four columns: four consecutive WALK cycle poses, left foot forward, passing, right foot forward, passing. All characters fully within own cell with 55 pixels padding, centered horizontally, soles at y=445 relative to each cell, same head height and scale every cell. Character height approx 375 pixels. NO ground, NO floor, NO cast shadow, no surrounding scene, NO extra floating props. Exact 16 isolated figures arranged evenly. Preserve transparent empty padding for runtime sprite animation. This is an asset for a quarter-view fan game, not a poster.
```

실제 출력은 1254×1254이다. 요청한 해상도와 차이가 있으며 동일한 정규화 UV로 사용한다.

## kadaku-environment.png

```text
Use case: stylized-concept. A GAME ENVIRONMENT PROP ATLAS, exact 4 columns x 2 rows, 8 equal square cells, square corners no grid lines, transparent PNG background with real alpha. Wide 2048x1024 image. Orthographic isometric camera looking down 35 degrees, realistic high-detail pre-rendered dark sci-fi jungle assets inspired by Kadaku in Space Marine 2. Upper left overcast daylight highlights, deep green moss, rusty metals and damp stone. Row 1 cells left to right: 1 tall twisted tropical jungle tree trunk with hanging vines and irregular broadleaf green canopy, 2 different gnarled jungle tree with ferns and broad ragged leaves, 3 cluster of mossy angular grey rocks, 4 dense low cluster of ferns with several broad tropical leaves. Row 2 left to right: 1 ruined gothic sci-fi stone pillar with pointed arches and corroded iron detailing, 2 stack of battered olive military cargo crates with yellow hazard stripes, 3 broken rusted industrial pipe and valve cluster, 4 dark alien organic spore growth with purple sinewy ribs. Each complete isolated asset fits entirely inside its cell with 8 percent empty padding. Ground contact centered at 86 percent cell height. Tall objects fill height, low objects occupy lower half but don't draw a ground plane. NO ground tile, NO cast shadows, no labels, no text, no human characters, no scenery outside isolated objects, no background color. This will be sampled as a uniform 4x2 texture atlas in an OpenGL game.
```

실제 출력은 1774×887이다. 일부 예비 셀은 후속 배치에 사용할 수 있으며 현재 사용 셀은 나무·바위·기둥·상자·생체 장애물이다.

## tyranids-walk.png

```text
Use case: stylized-concept. Production game sprite atlas on TRUE TRANSPARENT background with alpha. Exact 4 columns x 3 rows equal square cells, canvas 2048x1536. No borders, no labels, no ground, no shadows. Realistic pre-rendered isometric Warhammer 40,000 Tyranids matching Space Marine 2 Kadaku tutorial, orthographic view looking down 35 degrees, facing screen down-left in every cell. Bone ivory chitin with deep purple carapace plates and dark red fleshy joints, sharp scything claws, sinewy tails, sinister alien morphology, highly detailed and readable at small scale. Row 1: the SAME Hormagaunt creature in 4 running gait frames, crouched narrow torso, two scything talons, long tail. Row 2: the SAME taller Tyranid Warrior in 4 running gait frames, elongated ridged skull, four arms with bone swords and talons, segmented purple armor, long tail. Row 3: the SAME massive Carnifex in 4 advancing gait frames, hunched bulky tanklike purple carapace, huge ivory scything claws, horned skull, powerful hooves. All full-body figures centered in their own cells, no overlap between cells, 10 percent transparent padding, feet at 90 percent cell height. Consistent shape, scale within each row, upper-left overcast lighting. This is a game-ready animation sheet, not a poster. Do not draw extra characters, scenery or any writing.
```

실제 출력은 1448×1086이다. 눈으로 확인한 행 구분과 알파 행 분포를 기준으로 세 행을 0~320, 320~678, 678~1086 범위에서 읽는다. 이미지 파일을 편집하거나 알파를 제거하지 않았다.
